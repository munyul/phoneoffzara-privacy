폰끄고자라 개인정보 처리방침

시행일: 2026년 10월 24일

계정과 정보 전송

폰끄고자라는 계정이나 로그인 없이 사용하는 앱이에요. 서버가 없으며 개인정보를 외부로 보내지 않아요.

기기에 저장하는 설정

취침 시간표, 허용 앱, 옵션 등의 설정은 사용 중인 기기에만 저장해요. 비상 해제 기록에는 입력한 약속, 해제 시각, 다시 잠근 시각 또는 세션 종료 시각, 그 구간의 앱별 사용 시간 요약을 기기 안에 30일 동안 보관해요.

접근성 서비스

잠금 중에만 현재 열린 앱을 확인하고, 허용하지 않은 앱을 잠금 화면으로 가리는 데 사용해요. 화면 내용이나 입력한 글자는 읽거나 저장하거나 외부로 보내지 않아요.

사용정보 접근

현재 열린 앱을 확인하고, 비상 해제 중 구간의 앱별 사용 시간을 계산하는 데 사용해요. 앱별 사용 시간 요약은 비상 해제 기록으로 기기 안에 저장하며 외부로 보내지 않아요.

다른 앱 위에 표시

다른 앱 위에 잠금 화면을 표시하는 데 사용해요.

알림

잠금 상태를 알리고, 비상 해제 중에는 입력한 약속을 표시하고 ‘다 했어요, 잘게요’ 버튼으로 다시 잠글 수 있게 해요. 잠금 전 알림을 켠 경우 잠금 시작 전에 미리 알려 드려요.

입력한 글

‘잠이 안 와요’에 입력한 글은 저장하지 않아요. 비상 해제에 입력한 약속은 비상 해제 기록으로 기기 안에 30일 동안 저장해요.

데이터 삭제

종료된 비상 해제 기록은 해제 시각으로부터 30일이 지난 뒤 앱이 다음에 실행될 때 삭제해요. 앱을 삭제하면 앱의 모든 데이터가 삭제돼요.
